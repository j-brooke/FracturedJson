# fracjson CLI Change Log

## 1.0.2

Updated to use FracturedJson library version 5.0.1.

* Fixed a [bug](https://github.com/j-brooke/FracturedJson/issues/64) where a blank line after a line comment would be written before the comment line rather than after.

## 1.0.1

Set `<InvariantGlobalization>true</InvariantGlobalization>` for greater compatibility with trimmed-down OS builds.

Initial release of the new **fracjson** CLI app.
